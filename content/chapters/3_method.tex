\section{Method}
\label{sec:method}

This section describes our evaluation framework for transferring frozen V-JEPA~2.1 features to aerial metric depth estimation and depth-aware semantic scene completion (SSC).  The method is intentionally organized as a sequence of probes and progressively more structured decoders.  This design separates four factors that are often confounded in end-to-end training: (i) the amount of aerial geometry already encoded in the frozen foundation representation, (ii) the decoder structure required to recover dense metric predictions from transformer tokens, (iii) the usefulness of predicted depth as a geometric prior for volumetric semantic occupancy, and (iv) whether explicit multiview correspondence improves the 3D prior beyond monocular depth estimation, and (v) whether altitude/intrinsics FiLM conditioning should also modulate the multiview geometry prior.  We use OccuFly~\cite{gross2026occufly} throughout because it provides RGB images, metric depth maps, camera calibration, semantic occupancy grids, and, for the pose-aware MVS branch, per-frame camera poses from real UAV viewpoints.

\subsection{Problem Formulation and Notation}
\label{sec:method_problem}

An OccuFly sample is represented as
\begin{equation}
    s_t = \left(I_t, D_t, M_t, Y_t, K_t, h_t, T_t^{w\rightarrow c}\right),
\end{equation}
where $I_t \in \mathbb{R}^{3\times H\times W}$ is an RGB frame, $D_t$ is a metric depth map, $M_t \in \{0,1\}^{H\times W}$ is the valid-depth mask, $Y_t$ is the semantic occupancy grid, $K_t$ is the camera intrinsic matrix, $h_t$ is the UAV altitude, and $T_t^{w\rightarrow c}\in\mathbb{R}^{4\times4}$ is the world-to-camera pose used by the multiview-stereo branch when pose supervision is available.  All depth experiments resize images to $384\times384$, which gives a $24\times24$ patch grid for a ViT backbone with patch size 16.  Depth values are clipped to $[d_{\min},d_{\max}]=[10^{-3},80]$ m for metric depth training and evaluation.

Depth supervision is resized with mask-aware interpolation rather than ordinary interpolation.  Given a depth map $D$ and validity mask $M$, the resized depth and mask are
\begin{equation}
    D' = \frac{\operatorname{resize}(D\odot M)}{\max(\operatorname{resize}(M),\epsilon)},
    \qquad
    M' = \mathbf{1}\{\operatorname{resize}(M)>0\},
    \label{eq:mask_aware_depth_resize}
\end{equation}
where losses and metrics are computed only on $\Omega_D=\{(u,v):M'_{u,v}=1\}$.  In the implementation, pixels outside the valid resized mask are assigned zero depth and ignored by all depth losses.

For SSC, OccuFly occupancy grids are stored in a raw width-height-depth layout and converted to the internal depth-height-width layout used by our training code:
\begin{equation}
    Y_{\mathrm{WHD}}\in\{0,\ldots,36,255\}^{192\times128\times128},
    \qquad
    Y_{\mathrm{DHW}}\in\{0,\ldots,36,255\}^{128\times128\times192}.
    \label{eq:occufly_grid_layout}
\end{equation}
The voxel grid covers
\begin{equation}
    x\in[-48,48]\ \mathrm{m},\qquad
    y\in[-32,32]\ \mathrm{m},\qquad
    z\in[0,64]\ \mathrm{m},
    \qquad \Delta=0.5\ \mathrm{m}.
    \label{eq:occufly_bounds}
\end{equation}
Label 0 denotes empty/free space, and label 255 denotes ignored or unknown voxels.  We write the semantic output space as $\mathcal{C}$ because it depends on the active SSC configuration: raw-ID-compatible FoundationSSC runs use raw slots $0,\ldots,36$, while CGFormer-style reporting remaps raw IDs to a contiguous empty-plus-occupied taxonomy before computing semantic metrics.  In all cases, $0$ denotes empty/free space and $\mathcal{C}_{\mathrm{occ}}=\mathcal{C}\setminus\{0\}$ denotes occupied semantic classes.

The monocular depth and SSC task functions are
\begin{equation}
    f_D: (I_t,K_t,h_t) \mapsto \hat{D}_t,
    \qquad
    f_S^{\mathrm{mono}}: (I_t,K_t,h_t,\hat{D}_t,P_t^D) \mapsto \hat{Y}_t,
\end{equation}
where $P_t^D$ is a categorical or Gaussian depth probability tensor used for geometric lifting.  For pose-aware multiview SSC, the target frame is paired with $N_s$ posed source views
\begin{equation}
    \mathcal{V}_t = \left\{(I_{t_i},K_{t_i},T_{t_i}^{w\rightarrow c})\right\}_{i=0}^{N_s},
    \qquad t_0=t,
\end{equation}
and the task function becomes
\begin{equation}
    f_S^{\mathrm{MVS}}:\left(\mathcal{V}_t,h_t\right)\mapsto \hat{Y}_t.
\end{equation}
In the multiview branches, the depth prior is produced by a pose-aware cost volume rather than by a monocular DPT-FiLM depth head.  The FiLM-conditioned variant further modulates the MVS depth-bin logits with altitude/intrinsics metadata before depth probabilities are formed.  We keep the V-JEPA~2.1 backbone frozen in all experiments.  This frozen-backbone protocol follows the common foundation-model transfer setting and makes the comparison diagnostic: improvements can be attributed to decoder design, metadata conditioning, temporal aggregation, depth-prior use, or multiview geometric matching rather than to representation finetuning.

\subsection{Frozen V-JEPA~2.1 Feature Extraction}
\label{sec:method_vjepa_features}

Let $E_{\theta}$ denote the frozen V-JEPA~2.1 encoder~\cite{murlabadia2026vjepa21}.  For an image input, the implementation uses the video-capable V-JEPA code path with a singleton temporal axis and extracts spatial patch maps.  For the ViT-Gigantic checkpoint used in the main experiments, the channel dimension is $C=1664$, the model has 48 transformer blocks, and a $384\times384$ image produces a $24\times24$ patch map.  We use either the final layer alone or four intermediate layers:
\begin{equation}
    \mathcal{L}_{\mathrm{G}}=\{11,23,37,47\},
    \qquad
    F_t^{(l)} = E_{\theta}^{(l)}(I_t)\in\mathbb{R}^{C\times24\times24},\quad l\in\mathcal{L}_{\mathrm{G}}.
    \label{eq:vjepa_multilayer_features}
\end{equation}
For the 40-block giant checkpoint used by helper code, the same relative-depth intent is mapped to $\{9,19,29,39\}$.  This checkpoint-aware mapping avoids accidentally requesting nonexistent transformer layers while preserving the early/mid/late feature sampling pattern.

For video experiments, a clip centered at target frame $t$ is
\begin{equation}
    X_t = [I_{t+\tau_1},\ldots,I_{t+\tau_T}]\in\mathbb{R}^{3\times T\times384\times384}.
\end{equation}
With V-JEPA tubelet size 2, the encoder returns
\begin{equation}
    G_t^{(l)}=E_{\theta}^{(l)}(X_t)
    \in\mathbb{R}^{C\times T'\times24\times24},
    \qquad T'=T/2.
    \label{eq:vjepa_video_features}
\end{equation}
For the implemented four-frame experiments, the target-centered real clip uses offsets $[-1,0,0,+1]$.  Thus the target frame is included twice; the repeated-frame control uses four copies of the target frame, and the shuffled-frame control deterministically shuffles the same target-centered indices.  We report these controls because they distinguish genuine temporal information from gains caused by repeated target evidence, batch-normalization effects, or increased input token count.

\subsection{Depth Estimation Heads}
\label{sec:method_depth_heads}

All depth heads produce a dense metric depth prediction.  Most variants first predict logits over $K_D=256$ depth bins and then convert them to metric depth by expectation,
\begin{equation}
    p_{k,u,v}=\operatorname{softmax}_k(z_{k,u,v}),
    \qquad
    \hat{D}_{u,v}=\sum_{k=1}^{K_D}p_{k,u,v}d_k,
    \label{eq:depth_expectation}
\end{equation}
where $d_k$ are bin centers.  The resulting map is resized to the supervision resolution and trained with a valid-pixel scale-invariant logarithmic loss.  For $N=|\Omega_D|$ valid pixels and $g_i=\log \hat{D}_i-\log D_i$, the loss is
\begin{equation}
    \mathcal{L}_{\mathrm{sig}} =
    \sqrt{\frac{1}{N}\sum_{i\in\Omega_D}g_i^2
    -\lambda_{\mathrm{si}}\left(\frac{1}{N}\sum_{i\in\Omega_D}g_i\right)^2 + \epsilon},
    \label{eq:sigloss}
\end{equation}
following the scale-invariant depth objective used in monocular depth estimation~\cite{eigen2014depth}.  We use this loss because aerial metric depth contains unavoidable global-scale ambiguity, while the altitude/intrinsics conditioning experiments test whether that ambiguity can be reduced by physically meaningful metadata.

\subsubsection{Image Linear Probe}
\label{sec:method_linear_probe}

The simplest probe tests whether metric depth is linearly accessible from the frozen final-layer feature map.  Given $F_t^{(47)}\in\mathbb{R}^{1664\times24\times24}$, the head is a synchronized batch-normalization layer followed by a $1\times1$ convolution:
\begin{equation}
    Z_t(:,u,v)=W\,\operatorname{BN}(F_t^{(47)}(:,u,v))+b,
    \qquad W\in\mathbb{R}^{256\times1664}.
    \label{eq:linear_probe}
\end{equation}
No spatial decoder, skip connection, or trainable backbone parameter is used.  This probe is intentionally restrictive: if it succeeds, depth is already directly organized in the final V-JEPA feature space; if it fails relative to structured decoders, the failure indicates that aerial geometry is present only in a form requiring spatial reassembly or nonlinear decoding.  The same linear-probe implementation also supports DINOv3-style dense prediction utilities, which provide the batch-normalized linear head and features-to-depth conversion used in our frozen-probe baseline~\cite{simeoni2025dinov3}.

\subsubsection{Spatio-Temporal Linear Probe}
\label{sec:method_stlp}

The spatio-temporal linear probe (ST-LP) is the video analogue of the image linear probe.  It asks whether V-JEPA~2.1 video features expose temporal depth cues in a form that can be decoded by a single location-wise linear map.  For a four-frame clip, $T'=2$ after tubeletization, and the selected final-layer tensor is
\begin{equation}
    G_t^{(47)}\in\mathbb{R}^{1664\times2\times24\times24}.
\end{equation}
We concatenate the temporal tubelet axis into channels:
\begin{equation}
    \widetilde{F}_t\in\mathbb{R}^{(2\cdot1664)\times24\times24},
    \qquad
    \widetilde{F}_t(t'C+c,u,v)=G_t^{(47)}(c,t',u,v),
    \label{eq:stlp_concat}
\end{equation}
then apply the same batch-normalized $1\times1$ depth-bin head as in Eq.~\eqref{eq:linear_probe}.  The trainable head therefore has $3328$ input channels for the four-frame setting.  Because the operation is still linear in the frozen spatio-temporal features, ST-LP is a controlled diagnostic for temporal representation quality rather than a high-capacity video decoder.

\subsubsection{DPT-FiLM Multiscale Depth Decoder}
\label{sec:method_dpt_film}

The structured image decoder follows the Dense Prediction Transformer (DPT) principle of reassembling transformer tokens from multiple layers into image-like feature maps and fusing them with convolutional refinement~\cite{ranftl2021dpt}.  For the four V-JEPA layers in Eq.~\eqref{eq:vjepa_multilayer_features}, each feature map is reassembled and projected to a common decoder width $C_D=256$:
\begin{equation}
    R_l = \rho_l\left(F_t^{(l)}\right),
    \qquad R_l\in\mathbb{R}^{C_D\times H_l\times W_l},
    \quad l\in\mathcal{L}_{\mathrm{G}},
    \label{eq:dpt_reassembly}
\end{equation}
where $\rho_l$ denotes the DPT reassembly and projection block.  The multiscale maps are then modulated by altitude and intrinsics through FiLM~\cite{perez2018film}.

The metadata vector is
\begin{equation}
    m_t=\left[
    \frac{h_t-40}{10},\frac{f_x}{W},\frac{f_y}{H},\frac{c_x}{W}-0.5,\frac{c_y}{H}-0.5
    \right]\in\mathbb{R}^{5},
    \label{eq:metadata_vector}
\end{equation}
where $(f_x,f_y,c_x,c_y)$ are camera intrinsics expressed relative to the image size used by the branch.  A small MLP maps $m_t$ to an embedding $e_t\in\mathbb{R}^{128}$.  For each DPT level,
\begin{equation}
    \widetilde{R}_l = R_l\odot\left(1+\gamma_l(e_t)\right)+\beta_l(e_t),
    \label{eq:film}
\end{equation}
where $\gamma_l$ and $\beta_l$ are learned affine projections.  We initialize the FiLM projections so that $\gamma_l\approx0$ and $\beta_l\approx0$ at the start of training, making the initial decoder identical to the unconditioned DPT path.  This avoids early training instability and lets the model learn when altitude or calibration should alter the feature scale.

The FiLM-modulated maps are fused by DPT refinement blocks and decoded into depth logits.  This decoder tests whether frozen V-JEPA layers contain spatially distributed aerial geometry that is not linearly accessible from the final map.  It also tests a physically motivated hypothesis: because UAV altitude and camera intrinsics determine the mapping from pixels to metric rays, exposing them to the decoder should improve metric scale recovery under altitude-dependent appearance changes.

\subsubsection{Final-Layer Simple Feature Pyramid DPT-FiLM}
\label{sec:method_sfp}

The final-layer Simple Feature Pyramid (SFP) variant isolates whether the last V-JEPA layer alone is sufficient when equipped with an explicit multiscale adapter.  Instead of extracting four transformer layers, we use only
\begin{equation}
    F_t^{(47)}\in\mathbb{R}^{1664\times24\times24}.
\end{equation}
A Simple Feature Pyramid inspired by ViTDet~\cite{li2022vitdet} converts this single map into four feature levels:
\begin{equation}
    \operatorname{SFP}(F_t^{(47)})=
    \{S_4,S_2,S_1,S_{1/2}\},
    \qquad
    S_s\in\mathbb{R}^{256\times(24s)\times(24s)},
    \quad s\in\{4,2,1,1/2\}.
    \label{eq:sfp}
\end{equation}
For a $384\times384$ input, these levels have spatial sizes approximately $96\times96$, $48\times48$, $24\times24$, and $12\times12$.  Unlike the four-layer DPT-FiLM decoder, this branch does not apply DPT reassembly to raw V-JEPA intermediate layers; the SFP itself creates the multiscale maps.  The resulting maps are projected, FiLM-conditioned with Eq.~\eqref{eq:film}, fused by the DPT depth head, and converted to metric depth.  This experiment distinguishes two possible explanations for DPT gains: multi-layer semantic hierarchy versus final-layer features plus a learned multiscale pyramid.

\subsubsection{Video DPT-FiLM with Dense Temporal Attention}
\label{sec:method_dta}

ST-LP is deliberately low capacity.  To test whether temporal evidence becomes useful when aggregated nonlinearly, we also evaluate a video DPT-FiLM decoder with dense temporal attention (DTA).  For each selected layer $l\in\mathcal{L}_{\mathrm{G}}$, V-JEPA returns
\begin{equation}
    G_t^{(l)}\in\mathbb{R}^{1664\times T'\times24\times24}.
\end{equation}
At each spatial site $(u,v)$, the temporal sequence is
\begin{equation}
    S_{t,u,v}^{(l)}=
    \left[G_t^{(l)}(:,1,u,v),\ldots,G_t^{(l)}(:,T',u,v)\right]
    \in\mathbb{R}^{T'\times1664}.
    \label{eq:temporal_tokens}
\end{equation}
The DTA adapter first reduces channels with a $1\times1\times1$ projection to an adapter width $A=512$, applies LayerNorm, and uses a learned query to attend over the temporal tokens with multi-head attention.  The attended token is refined by an MLP residual, expanded back to 1664 channels, and interpolated with the temporal mean:
\begin{equation}
    \bar{F}_{t}^{(l)}(:,u,v)=
    \mu_{t}^{(l)}(:,u,v)
    +\alpha\left(\operatorname{Expand}\left(\operatorname{MLP}\left(\operatorname{MHA}(q,K,V)\right)\right)
    -\mu_{t}^{(l)}(:,u,v)\right),
    \label{eq:dta}
\end{equation}
where $\mu_{t}^{(l)}=\operatorname{mean}_{\tau}G_t^{(l)}(:,\tau,:,:)$ and $\alpha=\sigma(a)$ is initialized to approximately $0.1$.  The output maps $\{\bar{F}_{t}^{(l)}\}_{l\in\mathcal{L}_{\mathrm{G}}}$ are then passed to the same DPT-FiLM decoder as the image-mode multiscale model.  The residual gate makes the initial model close to temporal averaging, while allowing training to learn stronger temporal aggregation if motion parallax or temporal continuity is useful.

\subsection{Depth Probabilities for Semantic Scene Completion}
\label{sec:method_depth_probabilities}

The SSC models require not only a dense depth expectation $\hat{D}$ but also a probability distribution over depth bins for frustum lifting.  Let $\mathcal{B}=\{d_1,\ldots,d_K\}$ denote the bin centers expected by the lifting module.  We use four probability sources depending on the branch.  When a monocular depth head directly outputs bin logits, we use the softmax probabilities from Eq.~\eqref{eq:depth_expectation}.  When the FoundationSSC LSS module expects a different bin definition, we rebuild a Gaussian distribution around the dense depth prediction:
\begin{equation}
    P^D_{k,u,v}=\frac{\exp\left(-\frac{(d_k-\hat{D}_{u,v})^2}{2\sigma_D^2}\right)}
    {\sum_{j=1}^{K}\exp\left(-\frac{(d_j-\hat{D}_{u,v})^2}{2\sigma_D^2}\right)}.
    \label{eq:gaussian_depth_distribution}
\end{equation}
For the FoundationSSC hybrid, the LSS depth centers are defined by
\begin{equation}
    \operatorname{dbound}=[0,64,0.25],
\end{equation}
which gives 256 depth bins over the 64 m OccuFly lifting range.  If the frontend and LSS bin counts differ, the implementation resizes the probability tensor along the depth dimension and renormalizes it.  If the bin count already matches, the Gaussian reconstruction in Eq.~\eqref{eq:gaussian_depth_distribution} preserves the dense-depth expectation to numerical precision.  This remapping is important because a small inconsistency between the depth distribution and the expected metric depth can translate into systematic voxel misplacement during lifting.  The unconditioned pose-MVS branch bypasses this Gaussian reconstruction: it constructs $P_t^{D,\mathrm{MVS}}$ directly by softmax-normalizing a regularized projective cost volume over metric depth-bin centers, and obtains $\hat{D}_t^{\mathrm{MVS}}$ by expectation.  The Pose-MVS-FiLM branch applies FiLM to the MVS depth-bin logits before the softmax and then computes dense depth from the resulting conditioned probability distribution.  Thus the LSS probability volume and the dense depth map used by voxel proposal describe the same ray-wise depth distribution.

\subsection{Depth-Aware Semantic Scene Completion}
\label{sec:method_ssc}

Our SSC study evaluates how depth priors can be used as geometric evidence for aerial semantic occupancy.  We implement four complementary branches.  The first is a CGFormer-based depth-prior comparison, which isolates the value of different monocular depth priors under a fixed CGFormer-style evaluation pipeline~\cite{yu2024cgformer}.  The second is a monocular V-JEPA/F2D/FoundationSSC hybrid that performs in-model probability lifting with real FoundationSSC modules~\cite{chen2025foundationssc}.  The third is a pose-aware multiview-stereo FoundationSSC hybrid that replaces the monocular depth-probability frontend with an explicit projective cost-volume estimator in the style of learned MVS cost volumes~\cite{yao2018mvsnet}.  The fourth, Pose-MVS-FiLM, keeps the same projective MVS geometry but FiLM-conditions the MVS depth-bin logits using altitude and camera intrinsics.  The distinction matters: the CGFormer branch compares external or precomputed depth priors, the monocular FoundationSSC branch tests learned single-image depth uncertainty, the pose-MVS branch tests calibrated multiview correspondence, and the Pose-MVS-FiLM branch tests whether metadata conditioning improves that multiview prior.

\subsubsection{CGFormer Depth-Prior Comparison}
\label{sec:method_cgformer}

CGFormer addresses camera-based SSC by combining context-aware voxel queries and geometry-aware transformer reasoning~\cite{yu2024cgformer}.  In our implementation, we use the CGFormer code path as a controlled SSC comparison layer with OccuFly preparation, depth-prior export, checkpoint evaluation, and pairwise comparison utilities.  The depth-prior variants include a Depth Anything V2 prior~\cite{yang2024depthanythingv2} and V-JEPA~2.1 DPT-FiLM priors exported from our altitude-conditioned depth estimator.  Holding the SSC evaluation path fixed while changing the prior allows us to ask whether V-JEPA-derived depth is more useful for aerial occupancy than a strong generic depth foundation model.

For CGFormer reporting, raw OccuFly IDs are remapped to a contiguous 22-label taxonomy consisting of empty/free space plus 21 occupied semantic classes.  Label 255 is ignored.  Completion metrics are computed on the binary occupied-vs-empty task, while semantic mIoU is computed only over occupied classes.  The currently implemented masked 3D projector variant uses independent random voxel masking; we therefore describe it as such and do not claim a mixed block/column/frustum masking strategy.

\subsubsection{V-JEPA/F2D/FoundationSSC Hybrid}
\label{sec:method_foundationssc_hybrid}

The integrated SSC model combines a frozen V-JEPA backbone, a features-to-depth (F2D) DPT-FiLM frontend, a geometry-aware 2D context adapter, and real FoundationSSC lifting and 3D decoding modules.  Its forward pass is
\begin{equation}
    (I_t,m_t,K_t)
    \rightarrow \{F_t^{(l)}\}_{l\in\mathcal{L}_{\mathrm{G}}}
    \rightarrow (\hat{D}_t,P_t^D,F_t^{\mathrm{DPT}})
    \rightarrow C_t
    \rightarrow (V_t^{\mathrm{LSS}},V_t^{\mathrm{Vox}})
    \rightarrow \hat{Y}_t.
    \label{eq:foundationssc_forward}
\end{equation}
Here $F_t^{\mathrm{DPT}}$ denotes the projected DPT feature produced by the depth frontend, and $C_t\in\mathbb{R}^{128\times48\times48}$ is the fused 2D context map used for lifting.

The context adapter projects each selected V-JEPA level to a common $48\times48$ grid and fuses the projected features with the DPT feature:
\begin{equation}
    C_t = \phi_{\mathrm{ctx}}\left(
    \left[\operatorname{up}_{48}\left(\pi_l(F_t^{(l)})\right)\right]_{l\in\mathcal{L}_{\mathrm{G}}}
    \oplus \operatorname{up}_{48}\left(\pi_D(F_t^{\mathrm{DPT}})\right)
    \right),
    \label{eq:context_adapter}
\end{equation}
where $\pi_l$ and $\pi_D$ are learned projections, $\operatorname{up}_{48}$ denotes resizing to the $48\times48$ feature grid, $\oplus$ is channel concatenation, and $\phi_{\mathrm{ctx}}$ is the fusion network.  This design follows the source/pathway separation advocated by FoundationSSC~\cite{chen2025foundationssc}: V-JEPA features provide semantic context, while $P_t^D$ supplies explicit geometric uncertainty.

\paragraph{LSS-style frustum lifting.}
Lift-Splat-Shoot (LSS) constructs frustum features by combining a context vector with a categorical depth distribution at each image location~\cite{philion2020lss}.  For context $C_t\in\mathbb{R}^{C_c\times H_f\times W_f}$ and depth probabilities $P_t^D\in\mathbb{R}^{K\times H_f\times W_f}$, the lifted frustum tensor is
\begin{equation}
    \Phi_{c,k,u,v}=C_t(c,u,v)P_t^D(k,u,v).
    \label{eq:lss_frustum}
\end{equation}
Using resized intrinsics $(f_x,f_y,c_x,c_y)$ and feature-cell centers
\begin{equation}
    u=(j+0.5)s,\qquad v=(i+0.5)s,
\end{equation}
where $s$ is the image-to-feature downsampling factor, a depth bin $d_k$ is unprojected as
\begin{equation}
    x=\frac{(u-c_x)d_k}{f_x},
    \qquad
    y=\frac{(v-c_y)d_k}{f_y},
    \qquad
    z=d_k.
    \label{eq:unprojection}
\end{equation}
The corresponding voxel index in the OccuFly grid is
\begin{equation}
    i_x=\left\lfloor\frac{x-x_{\min}}{\Delta_x}\right\rfloor,
    \qquad
    i_y=\left\lfloor\frac{y-y_{\min}}{\Delta_y}\right\rfloor,
    \qquad
    i_z=\left\lfloor\frac{z-z_{\min}}{\Delta_z}\right\rfloor.
    \label{eq:voxel_index}
\end{equation}
Frustum features falling into the same voxel are aggregated by the FoundationSSC LSS module.  The result is a low-resolution 3D feature volume that is further processed by proposal, VoxFormer-style reasoning~\cite{li2023voxformer}, dual-feature fusion, and the FoundationSSC 3D decoder.

\paragraph{OccuFly geometry rewrite.}
FoundationSSC was originally configured for street-level SSC geometry.  We therefore rewrite the geometry at module construction time before building LSS, proposal, VoxFormer, positional encoding, and OccHead modules.  With voxel downsampling $[2,2,2]$, the low-resolution OccuFly grid is
\begin{equation}
    (W_{\mathrm{low}},H_{\mathrm{low}},D_{\mathrm{low}})=(96,64,64),
\end{equation}
corresponding to the full-resolution grid in Eq.~\eqref{eq:occufly_grid_layout}.  The rewritten configuration is
\begin{equation}
    \mathrm{point\_cloud\_range}=[-48,-32,0,48,32,64],
\end{equation}
\begin{equation}
    \operatorname{xbound}=[-48,48,1.0],\quad
    \operatorname{ybound}=[-32,32,1.0],\quad
    \operatorname{zbound}=[0,64,1.0],\quad
    \operatorname{dbound}=[0,64,0.25].
    \label{eq:foundationssc_bounds}
\end{equation}
This rewrite prevents stale SemanticKITTI-like dimensions from entering the aerial model.  The expected tensor shapes are
\begin{equation}
    V^{\mathrm{proposal}}\in\mathbb{R}^{B\times1\times96\times64\times64},
    \quad
    V^{\mathrm{LSS}}\in\mathbb{R}^{B\times128\times96\times64\times64},
    \quad
    V^{\mathrm{Vox}}\in\mathbb{R}^{B\times128\times96\times64\times64},
\end{equation}
with final logits
\begin{equation}
    O\in\mathbb{R}^{B\times |\mathcal{C}|\times128\times128\times192}.
    \label{eq:ssc_logits_shape}
\end{equation}
The output is permuted into internal DHW order before loss and evaluation.

\paragraph{Depth detachment and warm starting.}
By default, the depth probability tensor passed to SSC is detached, and the V-JEPA backbone remains frozen.  The depth frontend can be initialized from a monocular depth checkpoint, but the warm start loads only the depth metadata encoder, DPT decoder, and FiLM blocks.  It does not load a separate DPT branch into the context adapter and does not update the V-JEPA encoder.  This choice makes the SSC experiment a test of whether a fixed aerial depth prior can guide 3D semantics, rather than an unconstrained joint optimization in which SSC gradients may distort the depth estimator.



\subsubsection{Pose-MVS-Cost-Volume FoundationSSC Hybrid}
\label{sec:method_pose_mvs_foundationssc}

The Pose-MVS-Cost-Volume FoundationSSC variant keeps the corrected OccuFly voxel geometry, LSS-style lifting interface, FoundationSSC hybrid view transformation, and SSC decoder from Sec.~\ref{sec:method_foundationssc_hybrid}.  It changes only the geometric frontend: instead of using a monocular DPT-FiLM depth-probability head, it constructs a metric depth-probability tensor from posed target/source video clips using the same reference-view cost-volume principle as MVSNet~\cite{yao2018mvsnet}.

For each target frame, the dataset returns a target-centered context clip and a set of MVS view clips
\begin{equation}
    X_t^{\mathrm{ctx}}\in\mathbb{R}^{3\times T\times H\times W},
    \qquad
    X_t^{\mathrm{mvs}}=\{X_{t_i}\}_{i=0}^{N_s}\in\mathbb{R}^{(1+N_s)\times3\times T\times H\times W},
    \qquad t_0=t,
\end{equation}
where the first MVS view is the target and the remaining views are neighboring source frames.  In the default configuration, $T=4$ and $N_s=2$, so the collated MVS tensor has shape $B\times3\times3\times4\times384\times384$, where the second dimension is target plus two source views.

The context path and geometry path are intentionally source-decoupled.  The context path encodes the target-centered clip, applies Dense Temporal Attention (DTA) within the target clip, and feeds the resulting DPT-compatible maps to a fresh DPT-FiLM dense feature head and the geometry-aware context adapter.  The geometry path flattens the MVS view dimension, encodes each view clip with the same frozen V-JEPA video backbone, applies DTA within each view, and reshapes the output back to view-specific feature maps:
\begin{equation}
    G_{i}^{(l)} = E_\theta^{(l)}(X_{t_i})\in\mathbb{R}^{C\times T'\times H_f\times W_f},
    \qquad
    F_i^{(l)} = A_l(G_i^{(l)})\in\mathbb{R}^{C\times H_f\times W_f},
\end{equation}
where $A_l$ is the DTA adapter for layer $l$, $H_f=W_f=24$ for $384\times384$ inputs, and $T'=T/2$ for V-JEPA tubelets.  Crucially, source views are not fused before matching; otherwise the geometry branch would lose the one-to-one association between a feature map and its camera pose.

A multi-layer view projector maps the selected V-JEPA layers to compact matching features.  For each view $i$, the projected maps are resized to the first selected feature grid, averaged across layers, refined by shallow convolutions, and $\ell_2$-normalized:
\begin{equation}
    \bar{F}_i = \operatorname{norm}\!\left(
    \phi_{\mathrm{mvs}}^{\mathrm{proj}}\!\left(\frac{1}{|\mathcal{L}_{\mathrm{G}}|}
    \sum_{l\in\mathcal{L}_{\mathrm{G}}}\operatorname{resize}\left(\pi_l(F_i^{(l)})\right)\right)\right),
    \qquad
    \bar{F}_i\in\mathbb{R}^{C_m\times H_f\times W_f},
\end{equation}
with $C_m=64$ in the default configuration.

Let $T_i^{w\rightarrow c}$ be the world-to-camera pose for view $i$.  The relative transform from target camera coordinates to source camera coordinates is
\begin{equation}
    T_{i\leftarrow 0}=T_i^{w\rightarrow c}\left(T_0^{w\rightarrow c}\right)^{-1}
    =\begin{bmatrix}R_{i\leftarrow0}&t_{i\leftarrow0}\\0&1\end{bmatrix}.
    \label{eq:pose_mvs_relative_pose}
\end{equation}
Intrinsics are scaled from the resized image coordinates to the V-JEPA feature grid.  For a target feature-grid coordinate $p=(u,v,1)^\top$ and metric depth hypothesis $d_k$, the target-camera 3D point is
\begin{equation}
    X_0(d_k,p)=d_k\,\widetilde{K}_0^{-1}p,
    \label{eq:pose_mvs_target_point}
\end{equation}
and its projection into source view $i$ is
\begin{equation}
    p_i(d_k,p)\sim
    \widetilde{K}_i\left(R_{i\leftarrow0}X_0(d_k,p)+t_{i\leftarrow0}\right).
    \label{eq:pose_mvs_projection}
\end{equation}
The source feature map is bilinearly sampled at the normalized grid coordinate corresponding to $p_i(d_k,p)$.  Invalid projections behind the source camera or outside the source feature grid are masked.

The raw projective cost volume is a valid-source average of cosine correlations, following the standard learned-MVS pattern of matching target/source features over metric depth hypotheses~\cite{yao2018mvsnet}:
\begin{equation}
    S_{i,k}(p)=\left\langle \bar{F}_0(p),
    \operatorname{sample}\left(\bar{F}_i,p_i(d_k,p)\right)\right\rangle,
\end{equation}
\begin{equation}
    C_k^{\mathrm{MVS}}(p)=
    \frac{\sum_{i=1}^{N_s}V_{i,k}(p)S_{i,k}(p)}
    {\max\left(\sum_{i=1}^{N_s}V_{i,k}(p),1\right)},
    \label{eq:pose_mvs_cost_volume}
\end{equation}
where $V_{i,k}(p)$ is the binary valid-warp mask.  Depth planes without any valid source projection are assigned a fixed invalid cost.  A lightweight 3D convolutional regularizer, analogous to cost-volume regularization in MVSNet~\cite{yao2018mvsnet}, converts the aggregated volume into raw depth logits,
\begin{equation}
    Z^{\mathrm{MVS}}=\rho_{\mathrm{3D}}\left(C^{\mathrm{MVS}}\right),
    \qquad Z^{\mathrm{MVS}}\in\mathbb{R}^{K\times H_f\times W_f},
\end{equation}
which are bilinearly upsampled to the FoundationSSC lifting resolution $H/8\times W/8$.

The unconditioned Pose-MVS branch forms a categorical distribution directly from these logits:
\begin{equation}
    P_{k,u,v}^{D,\mathrm{MVS}}=\operatorname{softmax}_{k}\left(Z_{k,u,v}^{\mathrm{MVS}}\right),
    \qquad
    \hat{D}^{\mathrm{MVS}}_{u,v}=\sum_{k=1}^{K}P_{k,u,v}^{D,\mathrm{MVS}}d_k.
    \label{eq:pose_mvs_depth_prob}
\end{equation}
With the default depth range and binning, $K=256$ and the dense MVS depth map has shape $B\times1\times48\times48$ for $384\times384$ input.

\subsubsection{Pose-MVS-FiLM-Consistent FoundationSSC Hybrid}
\label{sec:method_pose_mvs_film_foundationssc}

The Pose-MVS-FiLM variant keeps the projective matching, source-view handling, cost-volume regularizer, FoundationSSC geometry, and SSC decoder unchanged, but conditions the MVS depth output using the same FiLM~\cite{perez2018film} metadata contract as the DPT-FiLM depth decoder.  The metadata vector is
\begin{equation}
    m_t=\left[
    \frac{h_t-40}{10},\frac{f_x}{W},\frac{f_y}{H},\frac{c_x}{W}-0.5,\frac{c_y}{H}-0.5
    \right],
    \qquad e_t=\eta(m_t)\in\mathbb{R}^{128},
    \label{eq:pose_mvs_film_metadata}
\end{equation}
where $\eta$ is the metadata encoder.  A FiLM projection predicts depth-bin-wise affine parameters
\begin{equation}
    (\gamma_t,\beta_t)=\omega(e_t),
    \qquad \gamma_t,\beta_t\in\mathbb{R}^{K},
\end{equation}
and the projection $\omega$ is zero-initialized so that the FiLM path is the identity at initialization.  The upsampled MVS logits are then conditioned before the depth softmax:
\begin{equation}
    \widetilde{Z}_{k,u,v}^{\mathrm{MVS}}=
    \left(1+\gamma_{t,k}\right)Z_{k,u,v}^{\mathrm{MVS}}+\beta_{t,k},
    \label{eq:pose_mvs_film_logits}
\end{equation}
\begin{equation}
    P_{k,u,v}^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}}
    =\operatorname{softmax}_{k}\left(\widetilde{Z}_{k,u,v}^{\mathrm{MVS}}\right).
    \label{eq:pose_mvs_film_prob}
\end{equation}
The dense depth used downstream is not independently modulated.  It is computed as the expectation under the same FiLM-conditioned distribution:
\begin{equation}
    \hat{D}_{u,v}^{\mathrm{MVS}\text{-}\mathrm{FiLM}}
    =\sum_{k=1}^{K}P_{k,u,v}^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}}d_k.
    \label{eq:pose_mvs_film_expectation}
\end{equation}
This consistency constraint is important because FoundationSSC consumes the categorical depth distribution for LSS-style lifting and the dense depth map for the voxel proposal/context pathway.  If the two tensors encode different ray depths, the lifted feature volume and proposal prior can disagree.  The Pose-MVS-FiLM branch therefore uses probability-first FiLM conditioning: altitude/intrinsics metadata modulates the depth-bin logits, the softmax gives the conditioned distribution, and the dense depth is exactly its metric expectation.

If the MVS depth-bin centers differ from the FoundationSSC LSS depth-bin centers, probability mass is rebinned in metric-depth space before LSS:
\begin{equation}
    \bar{P}^{D,\mathrm{LSS}}=
    \mathcal{R}\left(P^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}};
    \mathcal{B}_{\mathrm{MVS}}\rightarrow\mathcal{B}_{\mathrm{LSS}}\right),
    \qquad
    \sum_k \bar{P}_{k,u,v}^{D,\mathrm{LSS}}=1.
    \label{eq:pose_mvs_film_rebin}
\end{equation}
The implementation preserves the predicted conditioned probability distribution when the source and target depth centers match, rather than regenerating a Gaussian distribution around the dense depth map.

The pair $(P_t^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}},\hat{D}_t^{\mathrm{MVS}\text{-}\mathrm{FiLM}})$ is passed to the same downstream FoundationSSC modules as the monocular and unconditioned MVS hybrids:
\begin{equation}
    (C_t,P_t^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}},\hat{D}_t^{\mathrm{MVS}\text{-}\mathrm{FiLM}},K_t)
    \rightarrow (V_t^{\mathrm{LSS}},V_t^{\mathrm{proposal}},V_t^{\mathrm{Vox}})
    \rightarrow \hat{Y}_t.
    \label{eq:pose_mvs_film_foundationssc_forward}
\end{equation}
This isolates the effect of adding physically meaningful metadata conditioning to the multiview geometric prior while keeping the projective cost volume and voxel decoder fixed.

\subsection{SSC Training Objective}
\label{sec:method_ssc_loss}

The SSC objective combines semantic voxel classification, MonoScene-style scaling losses, optional occupancy BCE, and depth supervision.  Let $O_q\in\mathbb{R}^{|\mathcal{C}|}$ be the semantic logit vector at voxel $q$, let $p_{q,c}=\operatorname{softmax}(O_q)_c$, and let $\Omega_V=\{q:Y_q\neq255\}$.  The semantic cross-entropy term is
\begin{equation}
    \mathcal{L}_{\mathrm{ssc-ce}}=
    -\frac{1}{|\Omega_V|}\sum_{q\in\Omega_V}w_{Y_q}\log p_{q,Y_q},
    \label{eq:ssc_ce}
\end{equation}
where the empty/free-space weight is reduced to $w_0=0.25$ by default.  Reweighting empty space is important in aerial occupancy grids because most voxels are empty, and unweighted CE can encourage high completion IoU at the expense of occupied semantic classes.

The semantic scaling loss encourages precision, recall, and specificity for each class rather than only per-voxel likelihood.  For class $c$, define soft counts over valid voxels,
\begin{align}
    \operatorname{TP}_c &= \sum_{q\in\Omega_V} p_{q,c}\mathbf{1}\{Y_q=c\}, \\
    \operatorname{FP}_c &= \sum_{q\in\Omega_V} p_{q,c}\mathbf{1}\{Y_q\neq c\}, \\
    \operatorname{FN}_c &= \sum_{q\in\Omega_V} (1-p_{q,c})\mathbf{1}\{Y_q=c\}, \\
    \operatorname{TN}_c &= \sum_{q\in\Omega_V} (1-p_{q,c})\mathbf{1}\{Y_q\neq c\}.
\end{align}
Precision, recall, and specificity are
\begin{equation}
    \operatorname{prec}_c=\frac{\operatorname{TP}_c}{\operatorname{TP}_c+\operatorname{FP}_c+\epsilon},
    \quad
    \operatorname{rec}_c=\frac{\operatorname{TP}_c}{\operatorname{TP}_c+\operatorname{FN}_c+\epsilon},
    \quad
    \operatorname{spec}_c=\frac{\operatorname{TN}_c}{\operatorname{TN}_c+\operatorname{FP}_c+\epsilon}.
\end{equation}
The semantic scaling loss applies binary cross-entropy toward 1 to these class-level quantities, averaged over classes present in the batch.  The geometric scaling loss uses the same construction for binary occupancy, with target $o_q=\mathbf{1}\{Y_q\neq0\}$ and predicted occupancy probability $p_q^{\mathrm{occ}}=1-p_{q,0}$.  This follows the motivation of prior monocular SSC losses: optimizing only voxel-wise CE can underemphasize small occupied structures and thin objects~\cite{cao2022monoscene}.

For the depth frontend inside SSC, we supervise both the probability distribution and the dense expectation.  Given ground-truth depth $D_i$ at valid pixel $i$, the soft target distribution is
\begin{equation}
    Q_{i,k}=\frac{\exp\left(-\frac{(d_k-D_i)^2}{2\sigma_Q^2}\right)}
    {\sum_j\exp\left(-\frac{(d_j-D_i)^2}{2\sigma_Q^2}\right)}.
\end{equation}
The depth classification loss is the soft cross-entropy
\begin{equation}
    \mathcal{L}_{\mathrm{depth-ce}}=
    -\frac{1}{|\Omega_D|}\sum_{i\in\Omega_D}\sum_k Q_{i,k}\log P^D_{i,k},
    \label{eq:depth_soft_ce}
\end{equation}
which is equivalent to a KL divergence up to the entropy of $Q$.  The relative depth L1 term is
\begin{equation}
    \mathcal{L}_{\mathrm{depth-l1}}=
    \frac{1}{|\Omega_D|}\sum_{i\in\Omega_D}
    \frac{|\hat{D}_i-D_i|}{\max(D_i,d_{\min})}.
    \label{eq:depth_rel_l1}
\end{equation}
For the pose-MVS branches, the same depth-supervision terms are applied to the cost-volume-derived distribution and expectation by substituting $P^D=P^{D,\mathrm{MVS}}$ and $\hat{D}=\hat{D}^{\mathrm{MVS}}$, or $P^D=P^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}}$ and $\hat{D}=\hat{D}^{\mathrm{MVS}\text{-}\mathrm{FiLM}}$, in Eqs.~\eqref{eq:depth_soft_ce} and~\eqref{eq:depth_rel_l1}.  Thus the cost-volume projector, regularizer, and depth temporal adapters receive direct metric-depth supervision whenever the MVS depth branch is trainable.  Freezing a randomly initialized MVS depth branch is not meaningful; frozen-depth ablations are reserved for the monocular DPT-depth branch.

The total optimized objective is
\begin{equation}
    \mathcal{L}=
    \lambda_{\mathrm{ce}}\mathcal{L}_{\mathrm{ssc-ce}}
    +\lambda_{\mathrm{sem}}\mathcal{L}_{\mathrm{sem-scal}}
    +\lambda_{\mathrm{geo}}\mathcal{L}_{\mathrm{geo-scal}}
    +\lambda_{\mathrm{occ}}\mathcal{L}_{\mathrm{occ}}
    +\lambda_{\mathrm{dce}}\mathcal{L}_{\mathrm{depth-ce}}
    +\lambda_{\mathrm{dl1}}\mathcal{L}_{\mathrm{depth-l1}}.
    \label{eq:total_loss}
\end{equation}
Unless stated otherwise, we use
\begin{equation}
    \lambda_{\mathrm{ce}}=1,
    \quad \lambda_{\mathrm{sem}}=1,
    \quad \lambda_{\mathrm{geo}}=1,
    \quad \lambda_{\mathrm{occ}}=0,
    \quad \lambda_{\mathrm{dce}}=0.5,
    \quad \lambda_{\mathrm{dl1}}=0.2.
    \label{eq:loss_weights}
\end{equation}
The occupancy BCE term is still computed and logged when $\lambda_{\mathrm{occ}}=0$, but it does not contribute to the optimized total.

\subsection{Evaluation Metrics}
\label{sec:method_metrics}

Depth models are evaluated only over valid pixels.  We report root mean squared error (RMSE), absolute relative error (AbsRel), and log-RMSE:
\begin{equation}
    \operatorname{RMSE}=\sqrt{\frac{1}{N}\sum_{i\in\Omega_D}(\hat{D}_i-D_i)^2},
    \qquad
    \operatorname{AbsRel}=\frac{1}{N}\sum_{i\in\Omega_D}\frac{|\hat{D}_i-D_i|}{D_i},
\end{equation}
\begin{equation}
    \operatorname{LogRMSE}=\sqrt{\frac{1}{N}\sum_{i\in\Omega_D}(\log\hat{D}_i-\log D_i)^2}.
\end{equation}
For video-depth runs we also compute the standard MAE, squared-relative error, and threshold accuracies $\delta_1,\delta_2,\delta_3$ when enabled by the evaluation script.

SSC evaluation follows the standard separation between scene completion and semantic scene completion.  Completion metrics treat all non-empty labels as occupied.  If TP, FP, and FN are counted over occupied-vs-empty predictions, then
\begin{equation}
    \operatorname{IoU}_{\mathrm{comp}}=\frac{\operatorname{TP}}{\operatorname{TP}+\operatorname{FP}+\operatorname{FN}+\epsilon},
    \quad
    \operatorname{Precision}=\frac{\operatorname{TP}}{\operatorname{TP}+\operatorname{FP}+\epsilon},
    \quad
    \operatorname{Recall}=\frac{\operatorname{TP}}{\operatorname{TP}+\operatorname{FN}+\epsilon}.
\end{equation}
Semantic mIoU is computed over occupied classes only, excluding empty/free space and ignore label 255:
\begin{equation}
    \operatorname{mIoU}=\frac{1}{|\mathcal{C}_{\mathrm{occ}}|}
    \sum_{c\in\mathcal{C}_{\mathrm{occ}}}
    \frac{\operatorname{TP}_c}{\operatorname{TP}_c+\operatorname{FP}_c+\operatorname{FN}_c+\epsilon}.
    \label{eq:ssc_miou}
\end{equation}
This metric choice is important for OccuFly because empty space dominates the voxel grid.  Completion IoU measures whether the model predicts occupied volume at all, whereas occupied-class mIoU measures whether those occupied voxels receive meaningful aerial semantics.  For the Pose-MVS and Pose-MVS-FiLM variants, depth metrics are computed on the target frame using the cost-volume expectation.  We additionally log the valid-warp fraction and number of source views as diagnostics for whether the projected source evidence overlaps the target frustum.  For Pose-MVS-FiLM, we also verify that $\sum_k P_{k,u,v}^{D,\mathrm{MVS}\text{-}\mathrm{FiLM}}=1$ and that the dense depth equals the expectation in Eq.~\eqref{eq:pose_mvs_film_expectation}.

\subsection{Implementation and Reproducibility Details}
\label{sec:method_reproducibility}

The backbone is frozen in all reported depth and SSC variants.  Depth linear-probe experiments use distributed data parallel training with synchronized batch normalization and a global batch size of 8 in the verified launcher.  The image DPT-FiLM and SFP variants train only decoder, depth-head, and FiLM parameters.  The video DPT-FiLM+DTA variant trains the DTA adapters and DPT-FiLM decoder while keeping the video backbone fixed.  Unless stated otherwise, depth heads are trained for 20 epochs with AdamW, weight decay, gradient clipping, and early stopping on the validation split; the DTA sweep uses the corresponding 30-epoch video configuration.  These choices are deliberately lightweight relative to full backbone finetuning so that the experiments remain probes of V-JEPA~2.1 transfer.

The FoundationSSC hybrid uses the corrected OccuFly geometry rewrite described in Eq.~\eqref{eq:foundationssc_bounds}.  The geometry-correction run is therefore a configuration and tensor-shape correction, not a new feature-extraction architecture.  The semantic-reweighting run changes loss balancing or class weighting over the corrected architecture.  The MDE warm-start run initializes only the monocular depth frontend components described above and, by default, freezes them during SSC optimization.  The Pose-MVS-Cost-Volume run is the architecture-level FoundationSSC variant that keeps the downstream FoundationSSC geometry and decoder fixed, but replaces the monocular depth-probability frontend with source-specific V-JEPA video features, pose-aware projective matching, a cost-volume regularizer, and cost-volume-derived depth probabilities.  The Pose-MVS-FiLM run adds an identity-initialized metadata FiLM layer on the MVS depth-bin logits and computes dense depth from the same conditioned probability distribution, so its gains should be attributed to metadata-conditioned multiview geometry rather than to a different voxel decoder.  These distinctions are retained in the paper to avoid attributing gains to architectural changes that were in fact caused by geometry correction, loss balancing, initialization, or multiview correspondence.
